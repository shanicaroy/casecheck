# Rubric

- `rubric.md` — the UXPective case-study storytelling framework, dimensions A–L, copied verbatim
  from the product contract §8. Read by the plan and check steps as prompt context. Never modified
  by code. Edit the text here to change what the tool looks for.
- `dimensions.json` — the same twelve dimensions as data the code can iterate: id, name, whether
  the contract marks it ★, whether it may be named the weakest part (`weakestEligible`: false for
  K, a cross-cutting flag, and for L, per the §8 scope note), and the two standing exceptions
  (K is cross-cutting, L is always light). No scoring lives here; the contract has none.
